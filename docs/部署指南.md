## 0. 部署架构总览

```
微信小程序（用户手机）
   │ HTTPS
   ▼
Nginx（443/80，域名 + SSL 证书）
   ├── /yoga/*  → 反向代理 → Rust Rocket 后端（127.0.0.1:8002）
   └── /images/* → 静态文件（IMAGE_DIR，头像/课表图）
   ▼
PostgreSQL（数据库 yoga，用户 psycho）— 全部业务逻辑在 fn_* 数据库函数中
```

部署分为四部分：**① 数据库 → ② 后端服务器 → ③ Nginx/HTTPS → ④ 小程序端发布**。

## 2. 数据库部署（PostgreSQL）

### 2.1 安装并初始化

```bash
sudo apt update && sudo apt install -y postgresql
sudo -u postgres psql <<'EOF'
CREATE USER psycho WITH PASSWORD '你的数据库密码';
CREATE DATABASE yoga OWNER psycho;
GRANT ALL PRIVILEGES ON DATABASE yoga TO psycho;
EOF
```

> 注意：数据库名 `yoga`、用户名 `psycho` 是**硬编码**在 `server/src/main.rs:32-33` 的。想改成别的名字，需同步修改这两个参数。

### 2.2 建表（关键坑：仓库没有建表脚本）

源码只附带了数据库函数（`server/src/handlers/*.md`），**没有 CREATE TABLE**。以下是根据函数 SQL 反推的建表脚本（先执行，若后面执行函数时报字段类型错误，按报错微调）：

```sql
-- 用 psql -U psycho -d yoga 执行
CREATE TABLE "user" (
    id            serial PRIMARY KEY,
    open_id       text,
    name          text,
    nick_name     text,
    avatar_url    text,
    phone         text,
    gender        int,
    address       text,
    note          text,
    user_type     int,
    creation_time bigint,
    updated_time  bigint
);

CREATE TABLE lesson (
    id   serial PRIMARY KEY,
    name text
);

CREATE TABLE coach (
    id           serial PRIMARY KEY,
    name         text,
    thumbnail    text,
    introduction text
);

CREATE TABLE course (
    id         serial PRIMARY KEY,
    lesson_id  int REFERENCES lesson(id),
    teacher_id int REFERENCES coach(id),
    date_time  bigint,   -- 当天 0 点的时间戳（秒）
    start_time int,      -- 当天开始时间（秒）
    end_time   int,
    peoples    int,      -- 容量
    class_type int,      -- 位掩码：1 小班 / 2 私教 / 4 团课
    hidden     int       -- 1 = 停课
);

CREATE TABLE reservation (
    id            serial PRIMARY KEY,
    course_id     int REFERENCES course(id),
    user_id       int REFERENCES "user"(id),
    fulfill       int,   -- 1 = 有效
    vc_id         int,   -- 所用会员卡
    creation_time bigint,
    updated_time  bigint
);

CREATE TABLE vip_card (
    id         serial PRIMARY KEY,
    user_id    int,
    card_id    int,      -- 1 周卡 / 2 月卡 / 3 年卡 / 4 次卡
    start_date bigint,
    end_date   bigint,
    times      int,
    hidden     int
);

CREATE TABLE slideshow (
    id    serial PRIMARY KEY,
    image text
);

CREATE TABLE "function" (
    id    serial PRIMARY KEY,
    name  text,
    image text
);

CREATE TABLE announcement (
    id           serial PRIMARY KEY,
    title        text,
    content      text,
    updated_time bigint
);

CREATE TABLE market (
    id           serial PRIMARY KEY,
    title        text,
    slogan       text,
    content      text,
    updated_time bigint
);

CREATE TABLE systeminfo (
    id            serial PRIMARY KEY,
    open_id       text,
    sdk_version   text,
    brand         text,
    model         text,
    pixel_ratio   text,
    platform      text,
    screen_height text,
    screen_width  text,
    version       text,
    ip            text,
    count         int,
    creation_time bigint,
    updated_time  bigint
);
```

### 2.3 创建数据库函数

把 `server/src/handlers/` 下所有 `.md` 文件里 ` ```pgsql ` 代码块中的 `CREATE OR REPLACE FUNCTION ...` 全部在 `yoga` 库执行。一次性导出的方法：

```bash
cd /Users/htjc/Downloads/wechat-yoga-miniprogram-main/server/src/handlers
# 把所有 .md 中的 pgsql 代码块拼接成一个 SQL 文件（用本机执行后拷到服务器，或直接在服务器上做）
for f in *.md; do awk '/```pgsql/{flag=1;next}/```/{flag=0}flag' "$f"; echo; done > /tmp/all_functions.sql
psql -h 127.0.0.1 -U psycho -d yoga -f /tmp/all_functions.sql
```

## 3. 后端服务器部署

### 3.1 安装 Rust 并编译

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# 上传或 clone server/ 目录到服务器，例如 /root/yoga-server/
cd /root/yoga-server/server
cargo build --release    # 产物在 target/release/（项目内 server 无独立名字，二进制名见 Cargo.toml package name）
```

> 课表图片生成所需的字体（PingFang.ttf）和模板图（pattern.png）已通过 `include_bytes!` 打进二进制（`server/src/handlers/schedule.rs:30-32`），无需额外上传。

### 3.2 环境变量与启动

| 变量 | 说明 |
|---|---|
| `DB_HOST` | 数据库地址（本机装就填 127.0.0.1） |
| `DB_PORT` | 5432 |
| `DB_PASSWORD` | psycho 用户密码 |
| `APPID` | 你自己的小程序 AppID |
| `SECRET` | 你自己的小程序 AppSecret |
| `IMAGE_DIR` | 头像/图片存储目录，如 `/var/www/yoga/images` |

```bash
sudo mkdir -p /var/www/yoga/images && chown -R 服务运行用户 /var/www/yoga
export DB_HOST=127.0.0.1 DB_PORT=5432 DB_PASSWORD=xxx
export APPID=wx你的appid SECRET=你的secret IMAGE_DIR=/var/www/yoga/images
./target/release/<二进制名>
# 监听 127.0.0.1:8002（Rocket.toml）
```

### 3.3 systemd 守护（推荐）

`/etc/systemd/system/yoga.service`：

```ini
[Unit]
Description=Yoga booking server
After=network.target postgresql.service

[Service]
WorkingDirectory=/root/yoga-server/server
Environment=DB_HOST=127.0.0.1
Environment=DB_PORT=5432
Environment=DB_PASSWORD=xxx
Environment=APPID=wx你的appid
Environment=SECRET=你的secret
Environment=IMAGE_DIR=/var/www/yoga/images
ExecStart=/root/yoga-server/server/target/release/<二进制名>
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now yoga
```

### 3.4 可选：用项目自带的 Deploy 工具

`Deploy/` 是作者写的 SSH 自动部署工具（打包 server 源码上传远端 cargo build）：

```bash
cd Deploy

cargo run
```

如果手动部署，可不用它。

## 4. Nginx + HTTPS

`/etc/nginx/sites-available/yoga`：

```nginx
server {
    listen 80;
    server_name 你的域名;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name 你的域名;

    ssl_certificate     /etc/letsencrypt/live/你的域名/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/你的域名/privkey.pem;

    # 后端 API
    location / {
        proxy_pass http://127.0.0.1:8002;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        client_max_body_size 10m;   # 头像上传上限
    }

    # 静态图片（头像等）
    location /images/ {
        alias /var/www/yoga/images/;
    }
}
```

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo nginx -s reload
sudo certbot --nginx -d 你的域名    # 自动签发并续期证书
```

验证：`curl https://你的域名/favicon.ico` 返回 404 JSON 即后端已通。

## 5. 小程序端配置与发布

### 5.1 修改域名（必做）

`miniprogram/app.js` 中：

```js
globalData: {
  host: 'https://lucidu.cn',        // ← 改成你的域名
  staticHost: 'https://lucidu.cn',  // ← 改成你的域名
}
```

> 天气接口硬编码为长沙（`WebAssembly/weixin/src/lib.rs`），非长沙门店需改后重新编译 WASM，或接受展示长沙天气。

### 5.2 微信开发者工具

1. 导入项目：选择 `wechat-yoga-miniprogram-main` 根目录，**AppID 换成你自己的**（覆盖 project.config.json 里的旧 appid）。
2. 开发调试：详情 → 本地设置 → 勾选「不校验合法域名」，即可连你服务器调试。
3. `miniprogram/pkg/` 下的 WASM 产物已编译好，前端逻辑改动才需要重新 `wasm-pack build`（见 `WebAssembly/*/README.md`）。

### 5.3 上线前微信公众平台配置

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 开发管理 → 开发设置 → 服务器域名：

- **request 合法域名**：`https://你的域名`
- **uploadFile 合法域名**：`https://你的域名`（头像上传）
- **downloadFile 合法域名**：`https://你的域名`（课表图下载分享）

### 5.4 发布

开发者工具 → 上传 → 公众平台提交审核 → 审核通过发布。

## 7. 已知坑（部署时留意）

1. **无建表脚本**：表结构是我从函数 SQL 反推的，个别字段类型（bigint/int/text）可能需按报微调。
2. **旧接口页面**：小班/私教/已约/公告/商城页面调用 `v1/*`、`yoga/booked/query` 等路由，当前后端**没有实现**，这些页面上线会报错/空白，需先在 Rust 路由中补齐或改走 `yoga/lessons`。
3. **天气接口硬编码长沙**、北京时间用淘宝接口——第三方接口稳定性无保障。
4. **无鉴权 token**：接口靠明文 openid，公网部署后任何人可伪造 openid 调管理接口（仅靠数据库 user_type 校验，但 openid 可猜测的前提是先拿到）。上线前建议至少给管理接口加一道签名。
5. **README 里的 `go run main.go` 已过时**：`server/src/main.go` 只是请求转储调试工具，真后端是 Rust，用 `cargo run`。
6. **会员卡不扣费**：约课不校验卡片（逻辑被注释），可以先无卡运营。
